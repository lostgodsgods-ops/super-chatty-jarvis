SUPER CHATTY JARVIS — WEBSITE PACKAGE

फाइलें:
- index.html: मुख्य वेबसाइट। Hosting पर यही फ़ाइल upload करें।
- robots.txt: Search/AI crawlers के लिए सामान्य crawl अनुमति।
- AI_AGENT_PROMPT.md: AI एजेंटों के लिए अलग project brief।

GitHub Pages पर प्रकाशित करने के लिए:
1. ZIP extract करें।
2. GitHub में एक repository बनाएं।
3. इस package की तीनों files repository के root में upload करें।
4. Settings → Pages → Deploy from a branch → main → /(root) → Save चुनें।
5. Pages में दिखाई देने वाला public URL खोलें।

ध्यान दें:
- वेबसाइट static है; इसमें वास्तविक account login, backend, AI API connection, investor payment, या inquiry form submission नहीं है।
- Investor inquiry केवल demo/preview है। किसी से पैसा न लें और संवेदनशील जानकारी न लें।
- सार्वजनिक repository में कोई API key, password, private data या secret upload न करें।
